# Security Policy

## Supported Versions

Scavo is a specialized, event-driven application with a limited support window. Only the latest version on the main branch receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, email **hello@wawand.co** with details. We aim to respond within 48 hours.

Please include:
- Description of the issue and potential impact
- Steps to reproduce
- Any suggested fixes

We will coordinate disclosure and credit reporters (unless anonymity is requested).
